# Orange Hot Water

Independent static website for `hotwaterorange.com`, designed for Cloudflare Pages.

Run `python build_site.py` to regenerate the HTML pages in `dist/`.

Cloudflare Pages settings:

- Build command: `python build_site.py`
- Build output directory: `dist`

The site intentionally displays no phone number. Before launch, activate and test `info@hotwaterorange.com`, confirm the second lead-recipient address, activate FormSubmit and verify delivery.
